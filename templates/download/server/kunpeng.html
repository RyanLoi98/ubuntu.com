Ubuntu Server for Huawei Kunpeng

Ubuntu Server for Huawei Kunpeng brings an optimized Ubuntu Server image to the Huawei Kunpeng SoC platform, opening the door to Huawei’s hardware acceleration and advanced microarchitectures.

This custom image fully supports Huawei Kunpeng BoostKit and its specific hardware ecosystem, including specialized network interface cards (NICs) and storage. The Kunpeng platform is designed for building out workloads in the data center, telecommunications, database, and AI spaces. With its unique deployment toolset (including Juju and MAAS), Ubuntu makes the management of those workloads straightforward.

Starting with Ubuntu 24.04 LTS, the Huawei Kunpeng 950 and 920 New Type processors are supported.

This is the custom ISO image of the Ubuntu Server installer.
